# small-projects

En samling af små Python-projekter, som jeg har lavet, mens jeg lærer.

## Projekter

- **guessing game**: hangman-lignende gættespil i terminalen med et tilfældigt ord og 12 forsøg.
- **webscraper**: følger tilfældige links mellem Wikipedia-artikler (requests og BeautifulSoup).
- **keylogger**: et lille sikkerhedsprojekt lavet til læring med pynput.
